# ClimateGuard AI Backend

FastAPI asynchronous backend for multi-source environmental data aggregation, verification, risk analysis, and anomaly detection.

## Quickstart

```bash
python -m venv .venv
source .venv/bin/activate  # Or on Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```
